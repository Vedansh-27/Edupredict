# Data Directory

## Dataset: Student Performance (Synthetic)

### Source
This project uses a **synthetic dataset** generated by `ml/generate_synthetic_data.py`.

The synthetic data mirrors the statistical structure of the UCI Student Performance Dataset:

> P. Cortez and A. Silva. *Using Data Mining to Predict Secondary School Student Performance.*  
> FUBUTEC 2008, Porto, Portugal, April 2008, EUROSIS, ISBN 978-9077381-39-7.  
> URL: http://www3.dsi.uminho.pt/pcortez/student.pdf  
> UCI Repository: https://archive.ics.uci.edu/ml/datasets/student+performance

### Important Notice
**The data in this directory is SYNTHETIC.**  
It was generated programmatically using `ml/generate_synthetic_data.py` with a fixed random seed (42) to ensure reproducibility.  
It is **not real student data** and must **not** be presented as such.

### Why Synthetic Data?
The UCI dataset is available under a creative commons license, but automated downloading during CI/CD pipelines is fragile (URL changes, server availability). Using a reproducible synthetic dataset:
- Guarantees deterministic builds.
- Requires no external network calls at training time.
- Produces a dataset with similar statistical properties for demonstrating the ML pipeline.

### Dataset Structure

| Column | Type | Range | Description |
|--------|------|-------|-------------|
| sex | categorical | M/F | Student sex |
| age | integer | 15–22 | Student age |
| Medu | integer | 0–4 | Mother's education (0=none, 4=higher) |
| Fedu | integer | 0–4 | Father's education |
| studytime | integer | 1–4 | Weekly study time (1=<2h, 4=>10h) |
| failures | integer | 0–3 | Number of past class failures |
| famrel | integer | 1–5 | Family relationship quality |
| freetime | integer | 1–5 | Free time after school |
| goout | integer | 1–5 | Going out with friends |
| Dalc | integer | 1–5 | Weekday alcohol consumption |
| Walc | integer | 1–5 | Weekend alcohol consumption |
| health | integer | 1–5 | Current health status |
| absences | integer | 0–74 | Number of school absences |
| G1 | integer | 0–20 | First period grade |
| G2 | integer | 0–20 | Second period grade |
| **G3** | integer | 0–20 | **Final grade (prediction target)** |

### Regenerating the Dataset
```bash
python ml/generate_synthetic_data.py
```

### Preprocessing Notes
- `sex` is label-encoded: M=1, F=0.
- All numeric features are passed through a StandardScaler in the sklearn pipeline.
- Feature order is fixed during training and must match at inference time.
- The exact feature list and order are stored in `models/model_metadata.json`.
